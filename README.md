
# @asalomeri/core-utils

Reusable core utilities for JavaScript/TypeScript projects.

## Installation

```bash
npm config set @asalomeri:registry https://npm.pkg.github.com
npm i @asalomeri/core-utils
```

## Usage

```ts
import { example } from '@asalomeri/core-utils'

console.log(example())
```

## Development

```bash
npm install
npm run lint
npm test
npm run build
```
